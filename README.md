# Kanban Board

React 기반의 Kanban Board 카피 프로젝트입니다.

기존 오픈소스 프로젝트를 참고하여 주요 기능과 UI를 직접 구현하고, React와 TypeScript의 활용 방법을 학습하는 것을 목표로 합니다.

## 목표

- React 컴포넌트 구조 이해
- TypeScript를 활용한 타입 관리
- Drag and Drop 기능 구현
- 상태 관리 및 데이터 처리
- 반응형 UI 구현

## 주요 기능

- [ ] 칸반 보드 레이아웃
- [ ] 컬럼 추가 및 삭제
- [ ] 작업 카드 추가, 수정 및 삭제
- [ ] 드래그 앤 드롭을 통한 카드 이동
- [ ] 컬럼 간 카드 이동 및 정렬
- [ ] 브라우저 LocalStorage 데이터 저장
- [ ] 반응형 레이아웃

## 기술 스택

- React
- TypeScript
- Vite
- Tailwind CSS
- dnd-kit
- LocalStorage

## 개발 목적

원본 프로젝트의 구조와 구현 방식을 분석하고, 주요 기능을 직접 구현하면서 프론트엔드 개발 역량을 향상시키는 것을 목표로 합니다.

이 프로젝트는 학습 목적으로 진행하며 원본 프로젝트와는 별개로 개발합니다.
